Projeto simples de site para empresa

Como usar:

1. Abra um terminal nesta pasta.
2. Rode:

```
node server.js
```

3. Abra http://localhost:3000 no navegador.

Arquivos principais:
- index.html: estrutura da página
- styles.css: estilos
- app.js: lógica de navegação e cálculos
- server.js: servidor estático simples
